# UniTrack

Single-university Transport & Travel Tracking System (Final Year Project).

See [docs/README.md](docs/README.md) for architecture, locked product rules, and phase plan.

## Quick start

```bash
# API
cd backend
copy .env.example .env
.\venv\Scripts\activate
pip install -r requirements.txt
python run.py

# Admin web
cd admin-web
npm install
npm run dev

# Mobile
cd mobile
npm install
npx expo start
```
